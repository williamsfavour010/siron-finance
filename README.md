# Siron Finance

Money in your twenties, in plain language. A personal finance reference site covering budgeting, saving, investing, country playbooks (US, Nigeria, UK, Canada, Ireland, Ghana, Sweden), real estate, earning more, spending and giving, insurance, and interactive tools.

## How it is built

The whole site is one self-contained file: `index.html`. All CSS and JavaScript are inline, there is no build step, and GitHub Pages serves it straight from the `main` branch.

To change the site, edit `index.html` and commit. Changes go live on GitHub Pages a minute or two after a push.

Live site: https://williamsfavour010.github.io/siron-finance/
